# 9 表调研模板单元格映射

标准模板（亚马逊市场调研报告）含 9 个工作表。**每次调研先用 `inspect_template.py` 侦察实际模板**——本文是参考映射，若模板结构有出入以侦察结果为准。

> 数据表（第 5 表）由引擎整表重建，无需逐格填写。

## 表1 调研基础信息（rows≈10, cols=4）

| 单元格 | 内容 |
|---|---|
| C4-C6 | 类目路径（大类/精准小类/关联小类） |
| D4-D6 | 各类目说明（混入情况/头部竞品归属） |
| C7 / D7 | 季节性结论（短语）/ 完整论证（含峰谷数据） |

## 表2 产品画像（rows≈13, cols=5）

| 单元格 | 内容 |
|---|---|
| A5 | 决策核心依据（4 条条列：最强验证卖点/高增长词/新品友好/价格利润） |
| B7 | 新品方向（产品类型/穿着对象/图案主题/设计风格/差异化配置） |
| C7/D7/E7 | 竞品1/2/3 画像（同结构） |
| C8-E8 | 评分（数字） |
| C9-E9 | 评分数（数字） |
| C10-E10 | 上架时间 `YYYY-MM-DD(N天)` |
| C11-E11 | 当季销量（数字，**新插入行需 DONOR_STYLES 从 C12 继承样式**） |
| B12 | 新品价格区间（文本）；C12-E12 竞品价格（数字） |
| C13-E13 | 对标竞品 N 完整分析（结构、优势、可超越点） |

## 表3 市场分析（rows≈65, cols=7）

| 区域 | 单元格 | 内容 |
|---|---|---|
| 标题 | A1 | `亚马逊市场调研报告 - 市场分析（英文名 中文名）` |
| 一、市场趋势 | C5-F8 | 核心词月搜趋势/市场容量/淡旺季/生命周期，每行=核心数据+总结分析+数据来源+置信度 |
| 二、价格带 | A10 小节标题；B12-B15 带标签；C/D/E/F 列 | 每带=商品数占比+销量占比+销售额占比 / 卖家占比 / 核心特征（代表商品）/ 机会判断 |
| 差异化方向 | B45-B48 标签 + 后续列 | 已验证的差异化路径（结构创新/身份词/礼盒化/全角色矩阵等） |
| 用户画像 | E53 等 | 决策者-使用者关系、礼赠链路 |

## 表4 竞品深度分析（rows≈49, cols=16）

| 区域 | 单元格 | 内容 |
|---|---|---|
| 竞品表 | A3-G9，每行一个竞品 | A=序号、C=链接文本（URL）、D=价格（数字）、E=上架时间、F=销量趋势、G=评论分析；B 列为图片（B7 起可能有 DISPIMG，清理见 xml-surgery.md） |
| 维度分析 | A12+ 标签、B/C 列 | 每行=差异化维度（标签）+ 竞品格局证据 + 可切入方向 |

竞品 C 列跳转目标通过 `SHEET_LINKS = {'竞品深度分析': {'C3': url, ...}}` 配置。

## 表5 竞品数据（数据表，整表重建）

模板中原是上次调研的原始导出（名称如 `202603竞品数据`）。引擎按本次 Product 导出重建全部行，并改名为本次调研年月（`DATA_SHEET`/`DATA_SHEET_RENAME`）。A 列（图片列）重建后为空属正常——商品主图链接保留在「商品主图」列。

## 表6 关键词流量分析（rows≈37, cols=7）

| 区域 | 单元格 | 内容 |
|---|---|---|
| 一、词清单 | A3 标题；B5-F19，每行一词 | B=关键词类型、C=关键词、D=月搜（数字）、E=CPC（数字）、F=竞争度（含 SPR/需供比）、G5=总结 |
| 二、点击集中度 | B23-F27 | 每行=核心词 + 集中/分散 + TOP点击数据 + 机会判断 |

| 二、净利与定价 | A13 标题；A14-C22 | 广告费/净利/红线/主力定价/礼盒定价/备货量/FBA参考/毛利参考/库存节奏 |

## 表8 可行性评估与落地动作（rows≈25, cols=4）

| 区域 | 单元格 | 内容 |
|---|---|---|
| 一、机会点 | C5-D9 | 5 行：市场/细分/产品/流量/品牌机会（A/B 列标签模板已有） |
| 二、风险与应对 | C13-D17 | 5-6 行风险（C=描述、D=应对）。B13/B17 等标签若需换新词一并写入 |

## 表9 合规与风险评估（rows≈30, cols=5）

模板合规结论（类目审核/认证/关税）通常**保留不动**，仅更新：
- C16/E16 外观专利风险（结合本品类结构特征）
- C19/E19 商标侵权风险（列出头部品牌）
- C20/E20 版权侵权风险（本品类图案元素）
- A30/B30 专利检索建议（USPTO D 类检索方向）

## 填写顺序建议

1. 先跑 analyze 脚本拿到全部数字
2. 按「数据表 → 词清单 → 市场分析 → 竞品 → 产品画像 → 供应链 → 可行性 → 合规 → 基础信息」顺序写 `content_data.py`（后写总结性表格，先写数据性表格）
3. 每张表写完即自查：数字与 JSON 一致？结论有数据支撑？
