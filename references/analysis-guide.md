# 分析方法论与指标口径

脚本产出数字，**结论由 agent 综合 PDF 报告 + JSON 输出 + 品类常识得出**。本文定义指标口径与推导框架。

## 一、卖家精灵指标口径

| 指标 | 口径 | 用途 |
|---|---|---|
| 月搜索量 | 近一个月该词 US 站搜索次数 | 市场需求规模 |
| PPC竞价 | 该词 SP 广告建议出价 | 流量成本 |
| SPR | SellerSprite Product Rank，让新商品进关键词首页所需的天数 | 0-10 新品易卡位；>50 难 |
| 需供比 | 月搜索量 ÷ 该词在售商品数 | >5 供不应求（蓝海信号）；<1 竞争过剩 |
| 点击集中度 | TOP1-TOP3 点击份额合计 | >50% 头部垄断；30% 左右可切入 |
| 留评率 | 评分数 ÷ 历史销量 | 转化质量参考 |
| 毛利率 | (售价-采购-头程-FBA-佣金)/售价，卖家精灵按同类成本估算 | 利润空间 |
| ABA排名 | 亚马逊品牌分析搜索词排名 | 大词验证 |

## 二、市场统计框架（analyze_products.py 输出）

样本 = Product 导出的 50-60 个 ASIN（关键词搜索结果页头部）：

1. **市场容量**：月总销量/总销售额/ASP/单 ASIN 均销量。配合 PDF 报告的 100-ASIN 大盘（类目级）交叉验证——PDF 给类目趋势，导出给竞品明细。
2. **价格带（四带分析）**：默认 `$0-8 / $8-12 / $12-15 / $15-25`（可 `--bands` 调整）。每带统计商品数/销量/销售额占比 + 代表商品。判断逻辑：
   - 销量占比最高带 = **主流走量带**（新品定价锚点）
   - 销售额占比 > 商品数占比的带 = **客单价值带**（礼盒化机会）
   - 低于 FBA 费+佣金的带 = 引流带（低机会）
3. **竞争集中度**：Top10 销量占比、Top5 品牌占比、头部品牌是否本品类专精（综合品牌名/店铺判断）。
4. **评论门槛**：按评分数分档（0-50/50-100/100-500/500+）统计销量占比。500+ 评论占大头 → 新品难切入；样本 Top1 评论数 <100 → 新品友好。
5. **新品友好度**：上架 ≤15 个月（456 天）的销量占比；上架 ≤6 个月单品的销量表现。
6. **去重母体**：按父 ASIN 聚合（同款变体合并），Top 母体才是真实竞品排名。

## 三、关键词分层框架（analyze_keywords.py 输出）

按「流量层级 × 精准度」二维分层：

| 层级 | 定义 | 策略 |
|---|---|---|
| 场景-泛流量 | 礼物/场景大词（如 bridal shower gifts），月搜 5 万+ | 婚季前 2-3 月 SP 广告截流，不作主打卡位 |
| 人群-泛流量 | 人群大词（如 bride accessories） | 变体埋词 |
| 核心-精准 | 品类主词（如 bride socks / groom socks） | 主打卡位 + 标题首位 |
| 身份词 | 身份表达词（如 wifey / hubby / bride to be） | 高增长新兴需求，变体族全覆盖 |
| 长尾-精准 | 精准长尾（如 bride pilates socks） | SPR 低词自然卡位 |

**季节性判断**：历史趋势里跨年月均值 ≥ 全年均值 15% 的月份 = 旺季；峰谷比 = 历史最高月 ÷ 最低月。峰谷比 >5 的强季节品需谨慎备货；2-4 的链路型需求（婚庆/节庆礼品）全年有底。

**长期趋势**：近 12 月均值 vs 前 12 月均值（脚本输出 yoy_trend）。

## 四、竞品对标框架

对 Top3-7 去重母体逐个输出：
- 产品结构（类型/对象/主题/风格/变体数/A+/视频）
- 数据（价格/评分/评分数/上架天数/月销/环比/毛利率/FBA费）
- 优劣势 → 新品可复制点与可超越点

**埋词归属**：关键词挖掘的 `#1-#3 前三ASIN与点击共享` 列 → 反推头部竞品主要靠哪些词获得点击，写入「竞品深度分析」埋词盘点。

## 五、利润模型（供应链成本与利润测算表）

```
售价 = 主流走量带上限或甜点带（市场数据支撑）
采购成本 = 产业带参考报价（袜类：诸暨/汕头/泉州；宠物用品等按品类调整）
头程 = 海运按体积重摊销（包装尺寸来自导出「包装尺寸」列）
FBA费 = 竞品实测区间中值（导出「FBA($)」列）
佣金 = 售价 × 15%（服装类目）
毛利 = 售价 - 采购 - 头程 - FBA - 佣金
广告 = 营收 × 15%（新品期基准）
净利 = 毛利 - 广告
盈利红线 = 净利率 ≈ 10% 的售价（低于此无操作空间）
```

定价建议：主力价（走量带上限）+ 礼盒价（客单价值带对标）双档。

## 六、结论输出要求

每张表的「总结分析」列必须：
1. 有数据支撑（引用具体数字）
2. 有明确判断（机会/风险/动作）
3. 中文表达，结论前置（「XX是最佳切入带，因为…」而非「数据显示…可能…」）

置信度列：高=多源交叉验证；中=单源推断；低=经验估计。
