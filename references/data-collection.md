# 卖家精灵数据下载指南（4 类标准数据）

用户无法通过 API/MCP 获取数据时，指导其从卖家精灵网页版手动下载以下 4 类文件，放入调研工作目录。**下载前先与用户确认关键词（英文核心词）与站点（默认 US）**。

## 1. 竞品商品导出（必选）

**用途**：市场容量/价格带/品牌集中度/评论门槛/新品友好度/竞品明细/利润参考 的数据源。

**路径**：卖家精灵网页版 → 选品调研 → 商品搜索（Product Research）

**操作**：
1. 搜索框输入核心关键词（如 `bride and groom socks`），站点选美国
2. 默认按相关性/销量排序，勾选**前 50-60 个商品**（覆盖搜索前 3-4 页）
3. 点击导出（Export）→ 选择「商品数据」，字段全选（含 BSR/评分数/FBA费/毛利率/上架时间/A+与视频标识等 60+ 列）
4. 保存为 xlsx

**文件名特征**：`Product-US-YYYY.MM-数字.xlsx`（如 `Product-US-2025.12-218666.xlsx`）

> 注意：导出为「按 ASIN」的子体行；分析时需按「父ASIN」去重聚合（analyze_products.py 已处理）。

## 2. 关键词挖掘（必选）

**用途**：关键词清单（月搜/CPC/SPR/需供比/Top3点击归属）。

**路径**：关键词 → 关键词挖掘（Keyword Mining / Keyword Scout）

**操作**：
1. 输入核心关键词，站点 US
2. 导出相关词 Top 50+（含 `关键词/月搜索量/PPC竞价/SPR/需供比/商品数/#1-#3前三ASIN与点击共享` 等列）
3. 保存 xlsx

**文件名特征**：`KeywordMining-US-关键词-YYYYMM-数字.xlsx`

## 3. 关键词历史趋势（必选）

**用途**：季节性（旺季/淡季月份、峰谷比）、长期趋势、上新窗口判断。

**路径**：关键词 → 关键词历史趋势（Keyword History / 搜索趋势）

**操作**：
1. 从关键词挖掘结果中挑选 **20-50 个重点词**（核心精准词 + 高增长身份词 + 场景大词 + 人群词）
2. 勾选后查看/导出近 3 年逐月搜索趋势
3. 保存 xlsx（**每个关键词一个 sheet**）

**文件名特征**：`KeywordHistory-关键词(N)-US-YYYYMMDD-数字.xlsx`

## 4. 市场分析报告 PDF（必选）

**用途**：市场大盘（样本 100 ASIN 的销量/销售额趋势、ASP、上架时间分布、价格分布）——用于类目级容量与趋势，补充商品导出的样本偏差。

**路径**：选品调研 → 市场分析（Market Analysis）→ 输入关键词生成报告

**操作**：
1. 输入核心关键词生成市场分析报告
2. 导出/下载 PDF

**文件名特征**：`市场分析报告 - 关键词（中文名）.pdf`

> 注意：该 PDF 为**图片型（不可复制文本）**。用 `extract_pdf_report.py` 转分段图片后，由 agent 用视觉逐段读取关键数据（月销量/销售额/ASP/季节曲线/上架分布/价格分布）。

## 5. 关键词反查（可选，进阶）

**用途**：头部竞品的流量词归属（Listing 埋词分析）。

**路径**：关键词 → 关键词反查（Reverse ASIN）

**操作**：输入 Top3-7 竞品 ASIN，导出其排名关键词及排名位置。用于「竞品深度分析」表的埋词盘点部分。

## 下载完成后的核对清单

- [ ] 4 类文件均已在工作目录
- [ ] Product 导出打开后首行是表头（ASIN/品牌/月销量/价格($)...）
- [ ] 关键词挖掘含 `SPR`、`需供比` 列
- [ ] 历史趋势含 3 年逐月数据
- [ ] PDF 能打开（图片型正常）

核对通过后进入阶段 3 分析（见 SKILL.md 工作流）。
